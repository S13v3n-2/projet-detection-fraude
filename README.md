# projet-detection-fraude
Projet du cours Data Science.

DataSet : https://www.kaggle.com/datasets/kartik2112/fraud-detection?resource=download

Sujet : Optimisation du profit par la détection prédictive des fraudes transactionnelles.

Objectif : Ce projet vise à déployer un modèle d'apprentissage supervisé capable d'identifier les transactions 
frauduleuses avant leur compensation bancaire. On s'appuie sur l'analyse comportementale des clients porteur de carte, 
la banque passe d'une posture passive (remboursement après sinistre) à une posture proactive (prévention des fraudes). 
L'enjeu : sauvegarder la marge nette et renforcer la confiance avec le client.
